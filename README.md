# 拾光 · 日复盘

一个纯静态、本地优先的日复盘工具。记录保存在浏览器 `localStorage` 中，不需要后端数据库。

## 本地预览

双击 `打开日复盘预览.bat`，或访问 `http://localhost:4173/`。

## 私人本地使用

这个项目按“私人、本地优先”设计。双击 `打开日复盘预览.bat` 即可打开本地页面；如需开机自动启动，运行 `install-autostart.ps1`。

页面中的记录只保存在当前浏览器的 `localStorage`，不会自动上传到 GitHub，也不会发送到服务器。`数据与备份` 中的 JSON 文件属于私人数据，请不要提交到 GitHub。

如果曾经使用过 GitHub Pages，建议在 GitHub 仓库的 **Settings → Pages** 中选择 **Disable**，并把仓库改为 **Private**。仓库里的代码本身不包含你的复盘内容。

## 数据说明

复盘内容只保存在当前浏览器和当前设备中。更换设备或浏览器前，请使用页面中的导出功能备份数据；恢复时使用导入功能。旧版 `localhost:4173` 的记录也可以从“数据与备份”中迁移。
